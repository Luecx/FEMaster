\chapter{Complete Examples}
\label{chap:complete-examples}

The examples in this chapter combine the individual keyword pages into complete modelling workflows. Each section describes one physical problem and presents native FEMaster and supported Abaqus input side by side. The examples intentionally keep explicit sets, properties, boundary conditions, loads, and analysis controls so that the relation between the two input styles remains visible.

Native FEMaster defines reusable support and load collectors and activates them inside a \cmd{LOADCASE}. Abaqus input places supported \cmd{BOUNDARY} and load cards inside a \cmd{STEP}. Where the syntax differs, the examples use the exact FEMaster-supported representation rather than assuming that every feature of the full Abaqus product is available.

Several examples intentionally use node or element ID \val{0}. This demonstrates that zero is a valid FEMaster user ID; user IDs need not begin at one.

\section{Linear static truss}

The first model is a two-node axial bar in a consistent N--mm unit system. Node 0 is fixed and node 1 is guided so only axial translation remains free. A 1000 N force acts in the global \(x\)-direction. With
\[
E=210000\ \mathrm{MPa},\qquad
L=1000\ \mathrm{mm},\qquad
A=100\ \mathrm{mm}^2,
\]
the analytical displacement is
\[
u_x=\frac{FL}{EA}
=\frac{1000\cdot1000}{210000\cdot100}
\approx0.047619\ \mathrm{mm}.
\]
The case provides both a syntax template and a basic stiffness/reaction verification model.

\section{Nonlinear axial response with tabulated J2 plasticity}

The initial yield force for the 100\,mm\(^2\) section is \(A\sigma_y=25\,000\) N. The prescribed 27\,000 N tensile force is above this initial threshold; the nonlinear solution therefore requires constitutive history rather than merely using the elastic stiffness. \subsection*{Selecting a frequency band instead of a count}

To select every mode in an open 100--2000 Hz band from this native model, replace \cmd{NUMEIGENVALUES} and its data line with
\begin{syntax}
*EIGENVALUERANGE
394784.176, 157913670.
\end{syntax}
The values are \((2\pi f)^2\) in s\(^{-2}\), not frequencies. Modes exactly on either endpoint are excluded. The Abaqus version above remains count based. The three free axial DOFs leave room for a partial-spectrum solve: the first frequency is about 1308 Hz and the next lies above the selected upper limit. Requesting all three eigenvalues would violate the sparse solver requirement \(0<k<N\).

\section{Eigenfrequency with a concentrated MASS element}

Three identical, massless axial rods connect two interior mass nodes between fixed ends. Each interior node carries a one-node \val{MASS} element and is guided so only \(U_x\) is free. Requesting one eigenpair from these two free DOFs satisfies the sparse solver requirement \(0<k<N\).

The example uses N, mm, and s. In this consistent unit system the mass unit is tonne, because
\[
1\ \mathrm{N}\,\mathrm{s}^2/\mathrm{mm}=1\ \mathrm{t}.
\]
Thus each mass \(m=0.01\) represents \(10\,\mathrm{kg}\). Each rod has
\[
k=\frac{EA}{L}=\frac{210000\cdot1}{1000}=210\ \mathrm{N/mm}.
\]
The reduced matrices are
\[
K=k\begin{bmatrix}2&-1\\-1&2\end{bmatrix},\qquad
M=m\begin{bmatrix}1&0\\0&1\end{bmatrix}.
\]
The lowest mode has equal axial displacements at the two mass nodes, giving
\[
\omega_1=\sqrt{k/m}=\sqrt{21000}\approx144.914\ \mathrm{s}^{-1},
\qquad f_1=\frac{\omega_1}{2\pi}\approx23.064\ \mathrm{Hz}.
\]

\section{Linear harmonic frequency sweep}

The harmonic example evaluates a real axial harmonic force from 10 to 1000 frequency units at 100 linearly spaced points. The dynamic stiffness is
\[
K_\mathrm{dyn}(\omega)=K-\omega^2M+i\omega C.
\]
Rayleigh damping is added on the native side with a small stiffness-proportional coefficient. The current Abaqus input subset does not import an equivalent damping card in this example, so the two decks are identical in geometry and forcing but not in damping unless the native damping line is removed.

\section{Uniform thermal expansion of a solid}

This native example heats a unit cube from the material stress-free temperature of 20 to 120. With \(\alpha=10^{-5}\), the free linear strain is \(\alpha\Delta T=0.001\). Minimal axis constraints remove rigid motion while admitting uniform expansion; expected translations are \(u_x=0.001x\), \(u_y=0.001y\), and \(u_z=0.001z\), with zero thermoelastic stress up to numerical precision. \section{Two-node PIN constraint}

Two rods meet at coincident but separately numbered nodes 1 and 2. \cmd{MPC,PIN} equates their translations while allowing rotations to remain independent. \section{Using the examples as templates}

The examples follow the dependency order of the model: geometry and element connectivity precede regions, materials, and Sections; loads and constraints depend on those definitions; numerical solver controls act on the resulting analysis system.

The supported Abaqus input consists of the syntax documented in this manual. A keyword or option that exists in Abaqus itself is not automatically supported by FEMaster, and native FEMaster collector and Field keywords are part of an Abaqus deck only where such mixed use is explicitly documented.

The side-by-side layout is a modelling translation guide: the left and right columns express the same physical finite-element problem wherever both input styles support it. When one side lacks an equivalent feature, the text states the difference explicitly rather than hiding it behind an internal implementation detail.
