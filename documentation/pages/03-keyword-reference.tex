\chapter{Keyword Reference}
\label{chap:keyword-reference}

This chapter documents the unified FEMaster input language, combining supported Abaqus-compatible keywords with FEMaster-specific extensions. Commands are grouped by their role in model definition, properties, loading, constraints, analysis setup, and output. Section~\ref{sec:keyword-index} provides a compact index of the accepted keywords and element names.

\paragraph*{Reading the keyword pages}

Each keyword has one canonical location in this manual. Its entry explains
the modelling purpose, accepted parameters, and input data. Abaqus-
compatible definitions and FEMaster-specific extensions are part of
the same input language. Alternative forms are documented where useful;
some reference pages still display equivalent forms side by side.
The \cmd{ELEMENT} entry presents one common syntax with separate
examples only where alternative definitions are meaningful.
